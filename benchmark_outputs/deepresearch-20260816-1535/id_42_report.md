

# 深度研究报告：中小学生每天综合体育活动时间现状、影响因素与政策保障路径

## 摘要

2025年，中共中央、国务院印发的《教育强国建设规划纲要（2024—2035年）》明确提出“实施学生体质强健计划，中小学生每天综合体育活动时间不低于2小时”。这一要求将原有的“每天锻炼一小时”标准提升至新高度。然而，现实数据表明，我国中小学生体育活动时间严重不足，2023年北京市中小学生每天总体身体活动≥2小时的报告率仅为33.1%，远未达到全覆盖要求。本报告基于多项权威调查与学术研究，全面梳理当前中小学生体育活动时间的真实状况，深入剖析影响体育活动时间的多层次因素，并系统提出保障“2小时计划”落地实施的政策路径。

---

## 一、背景：政策迭代与目标升级

### 1.1 政策演进脉络

我国关于中小学生体育活动时间的政策经历了从“每天一小时”到“每天两小时”的跨越：

- **2007年**：中共中央、国务院印发《关于加强青少年体育增强青少年体质的意见》，强调“确保学生每天锻炼一小时”。
- **2020年**：中共中央办公厅、国务院办公厅印发《关于全面加强和改进新时代学校体育工作的意见》，提出“鼓励基础教育阶段学校每天开设1节体育课”，“着力保障学生每天校内、校外各1个小时体育活动时间”。
- **2025年1月**：中共中央、国务院印发《教育强国建设规划纲要（2024—2035年）》，明确提出“落实健康第一教育理念，实施学生体质强健计划，中小学生每天综合体育活动时间不低于2小时，加强校园足球建设，有效控制近视率、肥胖率”。
- **2025年11月**：教育部、国家发展改革委、财政部、人力资源社会保障部、体育总局等五部门联合印发《关于实施学生体质强健计划的意见》（即“学生体质强健20条”），对“2小时”要求进行系统部署。
- **2026年2月**：教育部发布《教育部关于全面推进健康学校建设的指导意见》，进一步强调落实“2小时”要求，推行“课间15分钟”。

### 1.2 目标设定

根据《关于实施学生体质强健计划的意见》，分阶段目标为：

- **到2027年**：以义务教育阶段为重点，中小学生每天综合体育活动时间不少于2小时要求全面高质量落实；学生体质健康合格率、优良率、毕业生运动习惯养成率显著提升。
- **到2035年**：现代化、高质量的学校体育体系基本形成，学校体育在促进学生健康成长、全面发展和教育强国建设中发挥重大作用。

## 二、中小学生每天综合体育活动时间现状

### 2.1 总体达标率极低

根据2023年北京市中小学生横断面调查数据（发表于《北京大学学报（医学版）》）：

- **每天总体身体活动≥2小时的报告率仅为33.1%**，即超过三分之二（约67%）的中小学生不满足当前国家要求。
- 每天在校身体活动≥1小时的报告率为64.8%，虽高于2019年全国平均水平（9~12岁：52.8%；13~15岁：41.2%），但仍未达到100%的覆盖要求。

### 2.2 群体差异显著

研究发现，不同群体学生的体育活动时间存在显著差异：

| 维度 | 群体对比 | 差异结论 |
|------|----------|----------|
| 学段 | 小学 vs 初中 | 小学生达标率（41.7%）显著高于初中生（24.6%） |
| 性别 | 男生 vs 女生 | 男生达标率（36.0%）高于女生（30.5%） |
| 学校类型 | 公办 vs 民办 | 公办学校（33.5%）高于民办学校（18.1%） |
| 区域 | 郊区 vs 城区 | 郊区学校（34.2%）高于城区学校（28.8%） |

### 2.3 全国性体质健康问题仍然突出

- **近视率**：2022年全国儿童青少年总体近视率为51.9%，其中小学生36.7%，初中生71.4%，高中生81.2%（国家疾控局监测数据）。
- **体质下降趋势**：自1985年以来，学生耐力、力量、速度等体能素质水平持续下降的趋势尚未得到根本性扭转。
- **大学生体质“洼地”**：代表学生身体机能水平的肺活量以及速度、爆发力、力量、耐力等素质在大学阶段全线下滑。
- **心理健康问题**：《中国国民心理健康发展报告（2021—2022）》显示，14.8%的青少年可能有一定程度的抑郁表现，约4%为重度抑郁风险群体。

### 2.4 国际比较

与发达国家相比，中国孩子的运动时间明显不足。资料显示，日本有40%的中小学生每天体育活动时间超过2小时。

## 三、影响中小学生体育活动时间的主要因素

基于多项学术研究（包括青少年身体活动促进模型、结构方程模型分析等），影响因素可归纳为以下四个层面：

### 3.1 个体层面

**（1）掌握的运动项目数量**

北京市研究显示，学生掌握的运动项目数量与每天总体身体活动≥2小时报告率呈**剂量反应关系**：掌握1项运动项目的学生达标率是掌握0项学生的1.74倍，掌握4项及以上则提升至2.70倍。掌握运动项目越多，活动乐趣体验和享受感越高，进行身体活动的意图越强。

**（2）感知身体活动益处与障碍**

- 感知身体活动益处得分越高，达标率越高（PR=1.40）。
- 感知身体活动障碍得分越高，达标率越低（PR=0.67）。
- 益处/障碍比值每增加1个单位，达标率提高24%（PR=1.24）。

**（3）自我效能感**

自我效能对学生活动量有显著正向预测作用，自我效能感高的学生更倾向于参与体育活动。

**（4）性别与年龄**

- 男生活动量普遍高于女生，女生更偏好羽毛球、乒乓球、健美操等低强度有氧运动。
- 高年龄段学生（尤其初中生）体育活动时间明显不足，与学业压力增大密切相关。

### 3.2 学校层面

**（1）体育课时被挤占**

长期以来，体育课被语数英等科目占用、老师拖堂或布置课间练习等现象屡见不鲜。中国教育科学研究院调研显示，全国能做到每天一小时体育锻炼的学校不到60%。

**（2）体育师资短缺**

截至2022年底，全国中小学体育教师配置总量超过72万，基本满足现行课标课时需求。但如果要求每天1节体育课并落实“每天2小时”，体育教师配置存在明显缺口。《意见》提出构建“以专职体育教师为主体、体育教练员为辅助、兼职体育教师和社会力量为补充”的新型体育师资队伍。

**（3）场地器材不足**

调查显示，45%和32%的学生认为场地器材缺乏是主要障碍。学校缺少足球、篮球、武术等器材，以及排球、羽毛球、武术等专项场地，限制了学生参与体育活动的积极性。一些学校甚至出现在篮球场上打羽毛球的情况，增加了受伤风险并降低了学生兴趣。

**（4）大课间活动质量不高**

以往大课间活动多采取跑步、做操形式，时间上“掐头去尾”，30分钟大课间有的只留下10分钟左右让学生运动，难以取得实效。

**（5）学校体育文化氛围**

拥有积极体育文化氛围的学校，学生参与体育活动的意愿和频率显著更高。

### 3.3 家庭层面

**（1）家长观念与行为**

中国教育科学研究院调查显示：**86%以上的家长不允许孩子放学后到户外活动**，主要出于安全保护和完成作业的考虑。家长对体育的认知程度、自身运动爱好、运动陪伴能力等，都直接影响孩子的体育活动时间。

**（2）家庭支持环境**

研究显示，家庭支持性环境得分与孩子活动量呈显著正相关（β=0.113，p=0.016）。家长的“填压式教育”倾向、优先安排文化课补习等行为，进一步压缩了孩子的体育活动时间。

**（3）家庭体育作业落实**

家庭体育作业需要家长陪伴、督促和指导，但受家长意愿和能力影响，落实效果参差不齐。

### 3.4 社会层面

**（1）生活方式变迁**

伴随经济发展，饮食结构、居住环境、交通方式的改变，导致能量摄入增加、体力活动减少。这是导致学生体质健康下降的关键宏观因素。

**（2）电子设备替代**

各种电子游戏、电视、手机、网络等逐渐替代了以体力活动为主的传统休闲方式，加剧了青少年户外活动减少。

**（3）社区支持环境**

社区体育设施的可及性和安全性，直接影响学生校外体育活动参与。研究显示，社区支持性环境得分与达标率呈正相关（PR=1.21）。

**（4）家校社联动机制不完善**

目前的家校社联动机制处于相对割裂状态。家庭、学校、社区之间缺乏有效沟通和合作，各自对自己的责任和资源认知不足，导致联动机制难以推进。

## 四、保障“2小时计划”实施的政策路径

### 4.1 深化体育教学改革，多途径保障时间

**时间保障措施：**

- **统筹课内外、校内外**：基础教育阶段积极推进中小学生每天综合体育活动时间不低于2小时。
- **开齐开足体育课**：按照规定课时开齐开足体育与健康课程，鼓励有条件的学校利用地方课程课时加强体育锻炼。
- **大课间制度**：鼓励有条件的中小学校上下午各安排一次不少于30分钟有质量的大课间体育活动。
- **课间15分钟**：推行“课间15分钟”制度，严禁“拖堂”或以其他方式挤占学生课间时间。
- **课后服务体育化**：把体育作为义务教育学校课后服务的必要内容，丰富体育项目。
- **寄宿制学校早操**：鼓励寄宿制学校在保障学生充分睡眠的前提下建立实施早操制度。
- **体育家庭作业**：探索布置学生独立或与家人共同完成的体育家庭作业。

**具体可操作模式**（参考先行探索经验）：

> 小课间“微运动”（8分钟×2次=16分钟）+ 大课间阳光运动（25—30分钟）+ 体育课教学活动（40分钟）+ 课后延时自主运动（30—35分钟）≈ 总计可达120分钟以上。

**质量保障：**

- 探索走班制、俱乐部制等实施方式，打破“一刀切”的授课模式。
- 促进学生立足学校即可熟练掌握至少一项运动技能，养成体育锻炼习惯。
- 确保运动安全与锻炼效果，强调体能、技能学习的连续性、进阶性、多样性。

### 4.2 健全训练竞赛与人才培养体系

- **形成“人人有项目、班班有活动、校校有特色、周周有比赛”** 的学校体育发展新样态。
- 以足篮排三大球为重点，大力开展形式多样的班级赛、校际赛。
- **中小学校每年举办春季、秋季学期两次校级综合性运动会或体育节**，确保每个学生经常参加校内体育竞赛活动。
- 构建定位清晰、层级分明、衔接有序、优质高效的竞赛体系。

### 4.3 加强师资队伍建设

- **配齐配强专职体育教师**，根据体育课程开设需要结合人口变化趋势动态调整。
- **构建新型体育师资队伍**：以专职体育教师为主体、体育教练员为辅助、兼职体育教师（教练员）和社会力量为补充。
- **保障同等待遇**：体育教师在职称（职务）评聘、福利待遇、评优表彰、晋级晋升等方面与其他学科教师享受同等待遇。
- 在学科带头人、特级教师、教学名师、教学成果奖等评选中保证体育教师占合理比例。

### 4.4 强化条件保障

- **场地设施升级改造**：将改进学校体育场地设施条件纳入各级各类学校升级改造总体安排。
- **挖潜拓展运动空间**：鼓励创设小型化运动锻炼场景，打造校内“微运动场”。
- **社会资源共用共享**：鼓励公共体育场馆设施免费或低收费向学校和学生公益开放；推进学校体育场馆课后、周末和寒暑假向学生免费开放。
- **数字赋能学校体育**：探索实施数字赋能学校体育，利用智能化手段提升活动组织效率。
- **强化安全保险机制**：建立健全学生体育活动意外伤害保险机制，解除家长、教师和校长的后顾之忧。

### 4.5 改进体育监测评价

- **深化体育评价改革**：将体质提升、技能增强、运动参与、习惯养成等作为评价重要指标，淡化考试选拔性、强化正向激励。
- **完善体质健康监测体系**：建立“监测—干预”联动机制，强化结果运用。
- **实施大学生体质提升专项行动**：要求各高校“一校一策”有效提升大学生体质健康水平。
- 建立学生体质健康测试抽查复核机制，落实结果公示反馈制度。

### 4.6 推进社会协同，构建家校社一体化支持环境

**家庭层面：**

- 家长做好“三件事”——**陪伴、督促、指导**。
- 鼓励家长运动陪伴，改变生活习惯，将陪伴孩子运动作为最有价值的亲子活动。
- 家长应了解家庭体育作业的内容、形式和量的要求，确保运动有效且安全。

**学校层面：**

- 发挥主导作用，统筹校内外体育资源，加强校内外联动。
- 通过布置家庭体育作业、在社区开展体育活动等措施带动家庭和社区体育文化氛围。
- 将大课间体育活动、课后延时体育活动以及课间“微运动”的组织管理责任分解到全体教师。

**社区层面：**

- 发挥辅助作用，提供场地和资源供学校和家庭开展体育活动。
- 配合学校开展身体活动健康教育活动，引进适合中小学生身体活动的赛事和机构。

### 4.7 分阶段推进与省级统筹

- **分步实施**：义务教育阶段，用一年时间在小学推广，逐步向初中普及；高中阶段确保“每天1小时”，在有条件的学校进行“每天2小时”尝试。
- **省级统筹**：各地教育行政部门制定实施方案，将落实“每天2小时”列入年度重点工作。
- **督导评估**：在省级人民政府履行教育职责评价、县域义务教育优质均衡发展督导评估中强化督导评估。
- **经费保障**：优化经费支出结构，健全多渠道投入机制，对学校必要的体育场地设施改造、器材配备经费适当倾斜。

### 4.8 关键在校长

各学校校长观念的转变，是疏通堵点、打通政策落实“最后一公里”的最重要一环。各学校要建立规范的管理制度和程序化的活动方式，长期坚持以形成常态化长效机制。

## 五、当前面临的挑战与对策建议

### 5.1 核心挑战

| 挑战类型 | 具体表现 |
|----------|----------|
| 时间冲突 | 学业压力大，文化课时间与体育活动时间结构性矛盾突出 |
| 师资缺口 | 若每天1节体育课加课后活动，现有体育教师总量不足 |
| 场地瓶颈 | 城市学校尤其是老城区学校运动空间严重不足 |
| 安全顾虑 | 运动伤害风险及责任分担机制不健全，校长和家长顾虑重 |
| 观念障碍 | “重智轻体”传统观念根深蒂固，部分家长和教师对体育价值认识不足 |
| 内容质量 | 活动形式单一、缺乏趣味性，难以激发学生内在动力 |
| 评价导向 | 升学考试指挥棒效应依然显著，体育评价权重有待提升 |

### 5.2 对策建议

1. **强化刚性约束**：将“2小时”落实情况纳入地方政府教育履职评价和学校考核体系，严禁“阴阳课表”、严查挤占体育课和课间活动时间。
2. **创新资源供给**：通过购买服务、聘请退役运动员、与社会体育机构合作等方式缓解师资和场地压力。
3. **完善安全保险**：加快建立全国性学生体育活动意外伤害保险机制，明确责任划分标准。
4. **深化家校合作**：通过家长学校、家长会等渠道普及体育健康知识，改变家长观念。
5. **科技赋能监测**：利用智能穿戴设备、大数据平台等，实现学生体育活动时间的精准记录和体质健康的动态监测。
6. **营造社会氛围**：广泛宣传“健康第一”理念，推介优秀案例，凝聚全社会共同促进学生体质强健的共识。

## 六、结论

《教育强国建设规划纲要（2024—2035年）》提出的“中小学生每天综合体育活动时间不低于2小时”目标，体现了国家对青少年体质健康的高度重视和坚定决心。然而，当前我国中小学生体育活动时间严重不足，2023年北京市数据显示达标率仅33.1%，全国范围内学生体质健康问题依然突出。影响体育活动时间的因素涉及个体、学校、家庭、社会四大层面，需系统施策、综合治理。

《关于实施学生体质强健计划的意见》提出的“二十条”举措，从教学改革、竞赛体系、师资建设、条件保障、监测评价、文化培育、社会协同等方面构建了完整的政策框架。关键在于地方政府、学校、家庭、社会各方形成合力，强化省级统筹、完善督导评估、创新资源配置、转变教育观念，真正将“健康第一”理念贯穿于教育全过程，确保到2027年实现“2小时”要求全面高质量落实的目标，为教育强国和健康中国建设奠定坚实的人才基础。
