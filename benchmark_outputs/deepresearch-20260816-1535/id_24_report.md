
# 增强自闭症学生课堂参与度：深度研究报告

## 摘要

自闭症谱系障碍学生在课堂参与方面面临独特挑战，包括社交沟通困难、感官处理差异、对变化的抗拒以及执行功能缺陷。本报告基于国内外最新循证研究成果，系统梳理了增强自闭症学生课堂参与度的有效策略。核心结论是：**不存在"万能方法"**，成功的关键在于个性化评估、策略组合使用以及全校参与的系统性支持。本报告涵盖结构化教学、视觉支持、同伴介入、积极行为支持、感官调节、社会故事、情绪调节训练、动机与强化策略，以及全校分层支援模式等九大领域，并提供具体实施方法和实证案例。

## 1. 引言：自闭症学生的课堂参与挑战

自闭症谱系障碍（ASD）是一种以社交沟通障碍、兴趣狭窄和重复刻板行为为核心特征的神经发育障碍。自闭症学生在课堂中面临的参与挑战包括：

- **社交沟通困难**：难以理解社交线索、发起或维持互动、跟随小组讨论
- **感官处理差异**：对声音、光线、触觉等刺激过度敏感或反应不足，导致注意力分散或行为不适
- **执行功能缺陷**：在计划、组织、任务启动和灵活性方面存在困难
- **对变化的抗拒**：常规变化或过渡期可能引发焦虑和问题行为
- **动机与强化历史**：可能因过往失败经验而缺乏学业参与动机

**关键原则**：自闭症学生存在高度异质性，没有一种策略适用于所有学生。有效的课堂参与提升策略必须基于个体化评估，并综合运用多种循证方法。正如《提升自闭症学生课堂参与度的有效策略》一文指出，需要分析每个策略的失效条件——例如视觉辅助可能对视觉敏感者适得其反。

## 2. 结构化教学（TEACCH）

### 2.1 概述

结构化教学（Structured Teaching）源于北卡罗来纳大学教堂山分校的TEACCH项目（Treatment and Education of Autistic and Communication Handicapped Children），由Eric Schopler教授等人于20世纪60年代开发。该策略充分利用自闭症学生的视觉优势，通过环境布置、视觉提示和工作系统来减少不确定性带来的焦虑，提高独立性和参与度。

### 2.2 核心要素（结构化教学金字塔）

**第一层：物理结构（Physical Structure）**
- 在教室中明确划分学习区、活动区、安静区等不同功能区域
- 使用家具、地毯、屏风等进行视觉分隔
- 减少无关刺激，帮助学生理解每个区域的用途

**第二层：视觉时间表（Visual Schedules）**
- 通过物件、照片、图标或文字展示活动顺序
- 帮助学生预知接下来会发生什么，减少焦虑
- 可从"先-后"卡片逐步过渡到详细日程表

**第三层：工作系统（Work Systems）**
- 回答四个问题：我要做什么？做多少？怎么做？做完后做什么？
- 通常使用左→右或上→下的任务组织方式
- 任务完成后有明确的"完成"标志

**第四层：视觉结构（Visual Structure）**
- 通过颜色编码、标签、图示等视觉提示帮助学生理解任务要求
- 明确指令——告诉学生从哪里开始、做什么、何时完成

### 2.3 实证效果

融合教育中的研究表明，结构化教学可将自闭症学生的任务完成率从40%提升至85%以上，并显著减少课堂离座和分心行为。结构化教学已被美国国家自闭症中心（National Autism Center）和NCAEP（National Clearinghouse on Autism Evidence and Practice）认定为循证实践。

### 2.4 实施要点

- 保持指令简洁、重复适当
- 根据学生兴趣选择教学材料
- 视觉提示需要与学生的认知水平匹配
- 需要与环境中的其他策略（如感官调节）配合使用

## 3. 视觉支持策略

### 3.1 概述

视觉支持（Visual Supports）是自闭症循证实践中最核心的策略之一，被NCAEP列为28种循证实践之一。其原理是利用自闭症学生相对较强的视觉信息处理能力，弥补其在听觉信息处理和社会认知方面的困难。

### 3.2 主要类型

| 类型 | 描述 | 应用场景 |
|------|------|----------|
| 视觉日程表 | 用图片/文字展示活动顺序 | 日常过渡、特殊活动预演 |
| 任务分析卡 | 将复杂任务分解为步骤 | 作业、手工、整理书包 |
| 行为期望图 | 展示课堂规则和期望行为 | 课堂管理、行为规范 |
| 选择板 | 提供有限选项 | 活动选择、休息时间 |
| 时间计时器 | 可视化剩余时间 | 活动过渡、任务时限 |
| 情绪温度计 | 展示不同情绪状态 | 情绪识别和自我调节 |
| 社交故事 | 图文结合的社会情境描述 | 社交技能、规则理解 |

### 3.3 实证效果

- 视觉活动时间表（Visual Activity Schedules）被证实为循证实践，可有效提升自闭症学生的独立性和任务参与度（Knight et al., 2015）
- 视觉支持帮助自闭症学生理解抽象概念（如"安静排队"），减少不确定性，降低焦虑
- 新泽西自闭症协会指出，视觉资料帮助儿童将抽象概念与实际体验联系起来，使过渡更顺畅

### 3.4 实施建议

- 图片需真实、清晰，与学生的认知水平匹配
- 社交故事中包含具体情境、人物、时间和地点
- 视觉支持应逐步撤除，以促进独立
- 对于语言能力有限的学生，使用真实照片和简单图标更为有效

**来源**：
- 新泽西州自闭症协会, 帮助自闭症儿童在新课堂或学校取得成功的五种方法: https://autismnj.org/zh-CN/article/five-ways-to-help-your-autistic-child-succeed-in-a-new-classroom-or-school

## 4. 同伴介入的教学与干预（PMII）

### 4.1 概述

同伴介入的教学与干预（Peer-Mediated Instruction and Intervention, PMII）是一种通过培训普通发展同伴来支持自闭症学生社交互动和学业参与的循证策略。PMII被NCAEP认定为28种循证实践之一，并被美国国家专业发展中心列为实证支持策略。

### 4.2 主要类型

| 类型 | 描述 | 适用场景 |
|------|------|----------|
| 同伴辅导 | 普通学生一对一辅导自闭症学生 | 学业任务、阅读、写作 |
| 同伴示范 | 普通学生展示目标行为 | 社交技能、课堂行为 |
| 同伴网络 | 建立支持性社交网络 | 社交融入、防止孤立 |
| 同伴启动 | 同伴主动发起互动 | 课间、自由活动 |
| 跨年龄同伴教学 | 高年级学生辅导低年级 | 社交技能、学业支持 |
| 同伴协助学习（PALS） | 轮流朗读、总结、预测 | 阅读和语言学习 |

### 4.3 实施步骤

1. **选择同伴**：选择具有适当社交技能、愿意参与、出勤良好的普通学生
2. **培训同伴**：教授同伴如何发起互动、给予提示、提供反馈
3. **结构化互动**：在结构化环境中安排同伴和自闭症学生互动
4. **自然情境实施**：将互动迁移到自然课堂情境中
5. **逐步撤除**：教师逐步减少提示，促进自主互动

### 4.4 实证效果

- 一项系统综述显示，PMII可显著提升自闭症学生的社交发起、回应和总体互动质量
- 在小学融合课堂中，同伴辅导使自闭症学生的社交互动时间从30秒提升至2分钟以上
- 同伴辅导同时提升普通学生的同理心、包容度和社交技能
- PEERS®项目（UCLA）显示参与者社交技能改善可维持3-5年

### 4.5 案例分析

案例一：一名社交能力较弱的自闭症学生担任英语"小老师"，通过一对一教学辅导两名普通学生，其主动社交行为显著增加，社交互动能力提升。该案例综合运用了视觉提示、社会故事、脚本和角色扮演。

案例二：在小学中，安排一名耐心且乐于助人的普通学生与自闭症学生配对，在小组合作活动中共同完成任务，给予提示和鼓励，显著减少了自闭症学生的孤立和退缩行为。

## 5. 积极行为支持（PBS）

### 5.1 概述

积极行为支持（Positive Behavior Support, PBS）基于应用行为分析（ABA），强调通过分析行为功能、优化环境条件和教授替代性技能来减少问题行为，增加积极行为参与。PBS不是简单的奖惩，而是系统性的行为干预框架。

### 5.2 核心要素

| 要素 | 描述 |
|------|------|
| 功能行为评估（FBA） | 分析行为发生的原因（如逃避任务、获取关注、感官刺激等） |
| 环境调整 | 改变引发问题行为的前事因素 |
| 替代行为教学 | 教授学生更合适的行为来满足需求 |
| 强化系统 | 对积极行为给予及时、具体的正强化 |
| 数据监控 | 持续收集数据评估干预效果 |
| 家校合作 | 确保策略在家庭和学校环境中的一致性 |

### 5.3 实施策略

- **任务调整**：对于因任务过难而逃避的学生，先降低任务要求，再逐步增加难度
- **差异化强化**：强化替代行为（如请求帮助替代发脾气）
- **非惩罚性反应**：对问题行为保持冷静、可预测的回应
- **正向指令**：使用"请坐好"而非"不要站起来"，明确告知期望行为

### 5.4 实证效果

- 三年级自闭症学生经过结构化教学与PBS后，任务完成率从40%提升至85%以上，离座行为明显减少
- 积极行为支持与正向行为干预（PBIS）框架结合，可显著改善全校范围内的学生行为参与
- 研究表明，PBS在与家庭合作时效果更持久，高参与度的家长对学生发展影响更显著

**来源**：

## 6. 感官调节与环境调整

### 6.1 概述

自闭症学生中约有80%-90%存在感官处理差异。感官调节困难会直接影响学生的课堂参与——过度敏感（如对噪音、光线反应强烈）或反应不足（如寻求高强度的感官输入）都会导致注意力分散、焦虑和行为问题。感官调节策略旨在帮助学生达到"冷静-警觉"的最佳状态，为学习创造条件。

### 6.2 分类策略

| 感官系统 | 挑战 | 策略 |
|----------|------|------|
| 听觉 | 噪音敏感 | 降噪耳机、安静座位、减少背景噪音 |
| 视觉 | 光线敏感、视觉过载 | 自然光、减少装饰、有色镜片、调整字体颜色 |
| 触觉 | 触觉防御 | 优先安排座位、允许使用安抚物品、避免意外触碰 |
| 前庭/本体 | 寻求或回避运动 | 摇摆椅、蹦跳休息、加重背心/垫 |
| 嗅觉 | 气味敏感 | 无香教室、通风良好 |

### 6.3 感官休息与感官饮食

- **感官休息（Sensory Breaks）**：在日程中安排定期的感官调节时间，如安静角落时间、运动休息
- **感官饮食（Sensory Diet）**：由作业治疗师设计的有计划的感官活动方案，帮助学生全天保持最佳唤醒水平
- **冷静角（Calm Corner）**：教室中设置一个低刺激、安全的空间，学生在情绪高涨时可暂时离开

### 6.4 实证效果

- Ayres感觉统合（Ayres Sensory Integration®）被NCAEP列为28种循证实践之一
- 系统综述表明，感官策略可帮助调节唤醒水平，从而优化参与度
- 环境调整（如减少视觉过载、提供安静空间）可显著降低自闭症学生的焦虑水平，提高课堂专注度

### 6.5 实施建议

- 感官策略需个体化——对一名学生有帮助的策略可能对另一名学生适得其反
- 与作业治疗师合作进行感官评估
- 观察学生的感官寻求/回避行为模式
- 策略需灵活调整，随着学生需求变化而改变

## 7. 社会故事与社交叙事

### 7.1 概述

社会故事（Social Stories™）由Carol Gray于20世纪90年代开发，是一种通过简短的、个体化的故事来描述社会情境、期望行为和社交规则的干预策略。社会故事结合文字、视觉和情境，帮助自闭症学生理解抽象的社会概念，减少不确定性带来的焦虑。

### 7.2 结构要素

社会故事通常包含以下类型的句子：

| 句子类型 | 功能 | 示例 |
|----------|------|------|
| 描述句 | 描述事实和情境 | "上课时，老师会站在前面讲课。" |
| 观点句 | 说明他人的感受和想法 | "同学们都知道，上课时要安静听讲。" |
| 指导句 | 提示期望行为 | "我可以举手发言。" |
| 肯定句 | 表达文化价值观 | "这样做对大家都好。" |
| 控制句 | 学生自己写的策略 | "当我感到紧张时，我可以深呼吸。" |

### 7.3 实施步骤

1. 确定目标行为或情境
2. 收集相关背景信息
3. 撰写社会故事（从学生视角出发）
4. 加入视觉支持（图片、照片、图标）
5. 与学生一起阅读和讨论
6. 配合理解问答和角色扮演
7. 在实际情境中泛化应用

### 7.4 实证效果

- 一项融合课堂研究（Scattone et al., 2006）对两名自闭症幼儿实施社会故事干预包，内容包括阅读故事、理解问答和角色扮演。结果显示：适当社交行为增加，不当行为减少，且效果维持长达10个月，涉及的学生在新学年进入一年级后依然保持进步
- 多媒体社会故事作为唯一干预措施时，可有效增加自闭症儿童的适当社交参与时长
- 社会故事特别适合用于处理过渡、规则理解、社交互动等情境

### 7.5 局限与注意事项

- 社会故事通常不是改变行为的唯一手段，需要与其他策略（如强化、提示）配合使用
- 对部分学生效果有限，需根据个体反应调整
- 社会故事应注重提供信息而非"告诉学生做什么"，避免变为指令清单

## 8. 情绪调节训练

### 8.1 概述

情绪调节困难是自闭症学生出现冲动、攻击性行为或退缩行为的核心原因之一。情绪调节训练帮助学生识别自己的情绪状态，学习恰当的表达和调节策略，从而减少情绪失控引发的行为问题，提升课堂参与度。

### 8.2 核心策略

| 策略 | 描述 | 工具/方法 |
|------|------|-----------|
| 情绪识别 | 教学生识别不同情绪状态 | 情绪卡片、情绪脸谱、情绪温度计 |
| 情绪表达 | 教学生用适当方式表达情绪 | 非语言交流卡、情绪日记、角色扮演 |
| 情绪调节 | 教学生降低情绪唤醒的策略 | 深呼吸、冷静角、感官策略、分心技术 |
| 自我监控 | 教学生自主监测情绪状态 | 自我评定量表、情绪记录表 |
| 社交问题解决 | 教学生应对社交冲突的步骤 | 社交剧本、情景模拟、问题解决流程图 |

### 8.3 实施方法

- **情绪温度计**：用颜色或数字表示不同情绪级别（如绿色=平静，黄色=有些紧张，红色=非常生气），帮助学生识别和表达情绪
- **冷静角**：教室中设置一个低刺激、安静的空间，学生可在情绪高涨时暂时离开，使用预设的调节策略
- **情景模拟与角色扮演**：在安全环境中练习应对挫折和冲突的策略
- **可视化工具**：情绪卡片、情绪轮盘等非语言工具帮助有沟通困难的学生表达情绪

### 8.4 实证效果

- 融合教育案例显示，情绪调节训练帮助一名情绪波动大的学生学会在生气时使用深呼吸和"冷静角"，成功避免了多次冲突
- 社交情感课程（SEL）整合心理理论、执行功能训练和情绪调节策略，可显著提升自闭症学生的同理心、情绪管理能力和社交策略使用
- 结合结构化教学和视觉支持的情绪调节训练效果更佳

## 9. 动机、强化与教学调整

### 9.1 概述

自闭症学生可能因过往失败经验、沟通困难、任务难度不匹配或缺乏兴趣而缺乏课堂参与动机。针对动机的干预策略至关重要，是提升课堂参与度的基础。

### 9.2 关键策略

**（1）基于兴趣的教学**
- 识别学生的特殊兴趣领域，并将其融入教学内容和活动
- 将兴趣嵌入社交学习情境（如小组游戏、讨论）
- 使用学生感兴趣的主题材料提高参与度

**（2）行为动量干预（Behavioral Momentum Intervention）**
- 先让学生完成几个简单的、高概率的任务，再要求完成较难的任务
- 利用"成功体验"建立动力
- 被NCAEP列为28种循证实践之一

**（3）强化系统**
- 使用具体、及时、频繁的正强化
- 强化物需个体化，基于学生的偏好评估
- 描述性表扬（"我喜欢你举手发言的方式"）优于笼统表扬

**（4）教学调整**
- 将任务分解为小步骤，设定可实现的目标
- 提供选择（如"你想先做数学还是语文？"）
- 使用多模态呈现（视觉+听觉+操作）
- 差异化作业难度

**（5）自我管理（Self-Management）**
- 教学生自我监控、自我记录和自我强化
- 提升独立性和自我调节能力
- 被NCAEP列为28种循证实践之一

### 9.3 实证效果

- 研究显示，在融合课堂中，基于兴趣的嵌入教学可显著提升自闭症学生的参与度和社交互动
- 自我管理策略帮助自闭症学生独立监控自己的行为，减少对成人提示的依赖
- 行为动量干预在减少逃避行为和增加任务参与方面具有显著效果

## 10. 全校分层支援模式

### 10.1 概述

提升自闭症学生课堂参与度不仅需要课堂层面的策略，更需要全校性的系统支持。香港教育局推行的"全校参与分層支援有自闭症的学生"三層支援模式（自2011/12学年起分阶段推行，2020/21学年起纳入常规运作）提供了一个系统化的参考框架。

### 10.2 三層支援模式

| 层级 | 目标对象 | 支持内容 | 策略示例 |
|------|----------|----------|----------|
| **第一层（全校性）** | 所有学生 | 营造自闭症友善校园环境，优化课堂教学 | 视觉策略、流程表、系统化常规、清晰要求、简单明确的指示 |
| **第二层（额外小组）** | 有额外需要的学生 | 提供社交沟通、情绪适应、学习适应的小组训练 | 社会适应技巧小组、情绪管理训练、社交技能小组 |
| **第三层（个别化）** | 适应困难较大的学生 | 跨三层的个别学习计划（IEP） | 一对一辅导、功能行为评估、个性化强化系统 |

### 10.3 实施机制

- **跨专业到校支援**：教育心理学家和计划人员为教师提供情境学习、实践引导、个案讨论、观课反馈、工作坊和联校网络交流
- **学校与非政府组织协作**：NGO专业人员根据学生需要设计并执行社会适应技巧小组训练
- **强项为本小组（Strength-Based Groups）**：基于学生优势设计小组活动，提升参与动力
- **家校合作**：定期与家长沟通，通过家长培训确保策略在家庭和学校的一致性

## 11. 策略整合与个性化实施

### 11.1 策略整合的必要性

单一策略难以应对自闭症学生的多元需求。行为问题可能涉及环境适应、情绪调节、社交互动、感官处理等多个方面。**综合运用多种策略可产生叠加效果**。

### 11.2 整合策略框架示例

| 教学环节 | 整合策略 |
|----------|----------|
| 课堂开始 | 视觉日程表（结构化教学）+ 情绪温度计（情绪调节）+ 强化问候（积极行为支持） |
| 小组活动 | 同伴配对（PMII）+ 结构化任务卡（视觉支持）+ 明确角色分配（结构化教学） |
| 独立作业 | 工作系统（结构化教学）+ 任务分解（教学调整）+ 自我监控表（自我管理） |
| 过渡环节 | 视觉时间表（视觉支持）+ 计时器+ 提前预告（感官调节）+ 过渡社会故事 |
| 情绪波动 | 冷静角（感官调节）+ 情绪卡片（情绪识别）+ 深呼吸（情绪调节）+ 事后行为分析（PBS） |

### 11.3 实施步骤

1. **全面评估**：了解学生的认知水平、语言能力、感官偏好、兴趣和挑战
2. **设定目标**：确定具体的、可测量的课堂参与目标
3. **选择策略**：基于评估结果和循证实践选择适合的策略组合
4. **培训团队**：确保教师、助教、家长、治疗师等所有相关人员都接受培训
5. **实施与监控**：持续收集数据，评估策略效果
6. **调整与优化**：根据数据反馈灵活调整策略

### 11.4 重要原则

- **个体化**：没有"万能方法"，策略必须基于学生个体特点
- **循证性**：选择经过研究验证的实践（NCAEP 28种EBP）
- **可持续性**：策略需在教师培训、资源保障和家校协作基础上持续实施
- **灵活性**：随时准备调整策略——对视觉辅助敏感的学生可能需要替代方案
- **优势导向**：关注学生的兴趣和优势，将其作为参与杠杆
