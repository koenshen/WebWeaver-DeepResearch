

# 市政污水收集处理从“核拨制”到高效治理的深度研究报告

## 1. 问题背景：核拨制下的效率困局

当前国内大部分城市对市政污水收集处理的财政拨付采取**核拨制**（即“按量核拨、收支两条线”）。该模式下，政府依据污水处理厂的处理水量（或固定预算）拨付运营费用，运营方缺乏提升收集效能、降低全生命周期成本的直接动力。其核心弊端可归纳为：

- **重水量、轻水质**：运营方关注进水量以获得更多拨付，对进水污染物浓度、管网完好率、雨污混接等缺乏主动治理意愿。
- **厂网分离、多头管理**：污水处理厂由环保企业或国企运营，市政管网归养护中心，老旧小区支管由物业代管，工业园区自建自管——各主体财务、考核、运维标准相互独立，无协同约束机制，导致“多龙治水、各自为政”的脱节格局[^1]。
- **资产台账缺失**：大量老旧管网、城中村接驳管缺少竣工图纸与权属登记，一旦进水浓度偏低或溢流，各方互相推诿，形成“考核有量化标准、事故无兜底主体”的局面[^1]。
- **财政资金效率低下**：政府按人头/规模拨付经费，而非按污染物削减效果付费，资金使用效率难以量化评估。

---

## 2. 核心改革方向：从“核拨制”到“按效付费”

### 2.1 按效付费机制的设计

按效付费（Performance-Based Payment）是打破核拨制低效的核心举措。该机制以**污水治理实际成效、管网运维品质、污染物削减总量**为核心标尺结算运维费用、落实绩效奖惩[^1]。

**关键考核指标**包括：
- 进水COD、BOD₅、氨氮浓度（反映管网收集效能）
- 污水收集率与管网完好率
- 雨季溢流频次与溢流污染控制效果
- 污泥无害化处理率

**付费公式示例**（以武汉市方案为参考）：
```
污水处理费实际拨付额 = 付费水量 × 基本价格 × 付费系数（J） - 违约扣减
```
其中付费系数J根据绩效考核最终得分确定，得分越高支付比例越高，低于70分可不予支付[^2]。

### 2.2 政策演进与地方实践

国家层面已明确推动“按效付费”改革：

- **2020年**，国家发改委等五部门联合印发《关于完善长江经济带污水处理收费机制有关政策的指导意见》，鼓励推行厂网一体化运营模式，开展收费模式改革试点，将管网运行维护费用纳入污水处理成本[^3]。
- **2022年**，国家发改委、住建部印发《关于进一步做好污水处理收费有关工作的通知》，要求各地结合厂网一体化运营模式创新完善污水处理收费政策[^3]。
- **2024年**，住建部等5部门印发《关于加强城市生活污水管网建设和运行维护的通知》（建城〔2024〕18号），明确要求“构建以污染物收集效能为导向的管网运行维护绩效考核体系和付费体系，对污水处理厂和管网联动按效付费”[^4]。
- **2025年**，住建部城市建设司发布《推进城市生活污水管网全覆盖及厂网一体长效机制建设工作指南》，提出建立以污染物集中收集效能和水环境质量提升为核心的绩效评价体系[^4]。

**地方实践案例**：
- **武汉市**：2023年出台《武汉市主城区城镇生活污水处理厂按效付费考核暂行办法》，将进水BOD₅浓度、污染物超量削减率等纳入考核，按得分确定付费系数，低于70分可拒付服务费[^2]。
- **桃源县**（湖南）：2022年印发《污水处理设施运营监督管理办法》，建立绩效考核评价机制实行按效付费，将运营补贴纳入县级财政预算，有效提升进水COD浓度和运行负荷率[^5]。
- **江西省**：2022年《城镇生活污水处理提质增效攻坚行动方案》提出，对实行“厂网一体”的，建立与进水浓度、污染物消减量挂钩的运营服务费核拨机制[^4]。
- **广东省**：2024年《深入推进“厂网一体”打好城镇生活污水治理攻坚战实施方案》要求探索以污染物收集效能为导向的管网运维绩效考核体系，按效付费[^4]。

## 3. 高效治理的操作性方案：六大支柱

### 3.1 推行“厂网一体化”运营管理

**核心思路**：将污水处理厂、排水管网、泵站等设施纳入统一主体进行规划、建设、运营和维护，实现“规划—建设—运管”全链条一体化。

**操作要点**：
1. **资产整合**：由地方政府牵头，将分散在各部门的管网资产通过股权收购、托管等方式整合至单一专业化排水公司，实行统一运营、统一调度、统一维护[^6]。
2. **分步过渡**：采取“成熟片区优先划转+过渡期管理”策略，避免一次性整合带来的运维真空。对老旧小区、工业园区管网设置两年过渡期，明确代管单位运维标准与月度考核细则[^1]。
3. **权责清单**：按市政主干、街巷支管、小区接驳、园区管网四类划定固定运维边界，编制官方权责清单并公示备案[^1]。

**典型案例**——珠海市：
- 2018年9月，珠海水控集团成立全资子公司“珠海供排水管网有限公司”，负责全市供、排水管网抢修、排水设施运营及养护。
- 三年来，通过排水管理体制改革，珠海排水系统厂网一体化格局基本形成，应急抢险机制成效明显，内涝防治能力大幅提升[^6]。

### 3.2 实施“按效付费”绩效考核体系

**操作路径**：
1. **建立指标体系**：将进水污染物浓度（BOD₅、COD）、污水收集率、管网完好率、雨季溢流频次等核心指标纳入考核范围[^2]。
2. **实行片区包干考核**：以街道、工业园区为单元划分独立考核片区，将核心指标分解至片区、责任单位及一线运维班组，实行“谁管护、谁负责”[^1]。
3. **付费系数动态调整**：根据考核得分确定支付比例，90分以上全额支付，70-90分按比例支付，70分以下可不予支付并限期整改[^2]。
4. **引入第三方审计**：强制第三方机构对运营数据进行实时审计和公开，确保考核客观公正。

### 3.3 建设智慧排水系统

**核心作用**：智慧化是实现精细化运维、降低综合成本的关键支撑。通过物联网、大数据、数字孪生等技术，实现从“被动应对”到“主动防控”的转变。

**操作要点**：
1. **管网数字化建档**：完成排水管网GIS系统录入，建立包含建设年限、管材、病害点位、权属信息的电子化资产台账[^6]。
2. **在线监测网络**：布设液位、雨量、流量及水质在线监测设备，实现厂、网、泵站、河道断面全链路数据实时采集[^7]。
3. **数字孪生与智能调度**：构建排水系统数字孪生平台，基于实时数据与模型算法，实现闸泵远程控制、溢流风险预判、应急快速处置[^7][^8]。
4. **AI辅助决策**：利用机器学习优化调度策略，如美国布法罗市采用BLU-X污水管网优化系统，在头一年就将合流制溢流量减少17亿升，预计节省至少1.45亿美元基础设施投资[^8]。

**国内实践**：
- **珠海市**：建立排水综合调度管理系统，完成各区排水管网普查资料的GIS录入，实现泵站在线监测及报警功能，正在按机械化、可视化、智能化目标建设[^6]。
- **连州市**：通过智慧排水综合管控系统，掌握管网现状，节省查找图纸和外出调查时间，系统级优化后期排水设施建设资金投入[^7]。

### 3.4 雨水与污水系统协同管理

**核心原则**：将雨水系统（排洪排涝）与污水系统（收集处理）视为一个有机整体，通过“厂网河（湖）一体化”运营管理模式，实现两大系统的协同运作与成本共担[^9]。

**操作方案**：

| 协同维度 | 具体措施 | 成本降低机制 |
|---------|---------|------------|
| **规划协同** | 统筹编制排水防涝与排污专项规划，实现雨污分流、排涝通道与污水管网同步规划 | 避免重复开挖，降低建设总成本 |
| **调蓄共享** | 利用雨水调蓄设施在旱季为污水系统提供调节容量，雨季为排涝系统提供削峰空间 | 减少独立调蓄设施投资 |
| **联合调度** | 建立“联排联调”机制，根据气象预警统筹河湖、水库、排水管网、调蓄设施的预腾空或预降水位 | 提升设施利用效率，降低应急成本 |
| **应急协同** | 排水防涝应急队伍与污水应急抢修队伍一体化建设，统一物资储备与调度 | 降低应急体系重复建设成本 |
| **数据共享** | 气象、水利、住建、生态环境等部门信息共享，完善雨情汛情预警预报和会商机制 | 提升预警精准度，减少灾害损失 |

**政策依据**：
- 国务院办公厅《关于加强城市内涝治理的实施意见》（国办发〔2021〕11号）明确要求“因地制宜推广‘厂网河（湖）一体化’运营管理模式”[^9]。
- 住建部等部委要求“建立城区水系、排水管网与周边江河湖海、水库等‘联排联调’运行管理模式”[^9]。

### 3.5 全生命周期资产管理

**核心思路**：将排水设施从建设到报废的全生命周期成本纳入统一规划，突破“重建设、轻运维”的传统思维。

**操作要点**：
1. **生命周期成本核算**：将收购成本、运营维护成本、修理成本、更换/处置成本全部纳入投资规划，认识到建造成本仅占50年生命周期总成本的一小部分[^10]。
2. **预防性维护制度**：从“事故性维护”转向“预防性维护”，建立周期性排查和养护制度，降低突发性大修成本[^6]。
3. **非开挖修复技术**：对主干道、商业街区等开挖受限区域，采用紫外光固化（UV-CIPP）、螺旋缠绕修复等非开挖工艺，显著降低交通干扰及社会成本[^11]。
4. **资产更新规划**：对存量管网进行结构性评估，制定分年度更新改造计划，避免“一次性大修”带来的财政冲击。

### 3.6 建立可持续的资金保障机制

**操作路径**：
1. **完善污水处理费征收机制**：合理调整收费标准，逐步将管网运行维护费用纳入污水处理成本，实现“谁污染、谁付费”[^3]。
2. **多元化投融资渠道**：充分利用中央预算内投资、超长期特别国债、专项债等资金，同时吸引社会资本参与（PPP/TOT模式）[^12]。
3. **按效付费与财政预算挂钩**：将运营补贴纳入财政预算，建立“以效定费、以效拨付”的动态调整机制[^5]。
4. **探索“排水管理进小区”**：将居住社区内部管网养护纳入市政排水管网运行维护体系，构建政府和居民共担的费用保障机制[^13]。

## 4. 雨水—污水协同运作的良性循环机制

### 4.1 协同运作的总体架构

```
┌─────────────────────────────────────────────────────────┐
│                    城市排水系统                          │
├───────────────┬─────────────────┬──────────────────────┤
│   雨水系统    │   污水系统      │    协同调度平台      │
│  (排洪排涝)  │  (收集处理)     │  (智慧排水系统)      │
├───────────────┼─────────────────┼──────────────────────┤
│·源头减排      │·管网收集        │·实时监测数据        │
│·管网排放      │·污水处理厂      │·数字孪生模型        │
│·调蓄设施      │·污泥处理        │·联排联调算法        │
│·河道行洪      │·再生水利用      │·应急指挥调度        │
└───────────────┴─────────────────┴──────────────────────┘
         ↓                    ↓                    ↓
    降低内涝风险         提升水环境质量      降低综合运营成本
```

### 4.2 良性循环的实现路径

**第一环——源头减排与收集效能提升**：
- 推进海绵城市建设，落实“渗、滞、蓄、净、用、排”措施，从源头减少雨水径流进入污水系统[^9]。
- 实施雨污分流改造，消除混错接，提高污水厂进水浓度，降低处理能耗[^11]。

**第二环——管网系统高效运行**：
- 通过智慧排水系统实现管网液位、流量实时监控，优化泵站运行，减少能耗和溢流[^7]。
- 预防性维护延长管网寿命，降低全生命周期成本[^6][^10]。

**第三环——污水处理厂优化运行**：
- 进水浓度提升后，生化处理效率提高，药耗、能耗下降[^14]。
- 污染物削减量增加，按效付费获得更高支付，形成正向激励[^2]。

**第四环——雨水资源化与再生水利用**：
- 初期雨水经调蓄处理后回用，减少水资源浪费。
- 污水厂尾水再生利用，缓解水资源短缺，降低城市供水压力。

**第五环——应急联动与韧性提升**：
- 极端天气下，智慧调度系统统筹排涝与污水处理，优先保障城市安全。
- 应急资源统一配置，减少重复投入，提高响应效率[^9]。

### 4.3 协同运作的成本降低测算

| 协同措施 | 预期成本降低幅度 | 依据 |
|---------|---------------|------|
| 厂网一体化运营 | 运维成本降低20%-30% | 珠海实践[^6] |
| 智慧排水系统 | 建设资金节省15%-30% | 连州、布法罗案例[^7][^8] |
| 预防性维护 | 大修成本降低40%-60% | 世界银行资产管理指南[^10] |
| 雨污分流改造 | 污水处理能耗降低15%-25% | 进水浓度提升后生化效率提高[^14] |
| 联排联调 | 应急设施投资节省20%-40% | 调蓄设施共享[^9] |

## 5. 政府管理部门操作建议清单

### 5.1 近期（1-2年）可启动事项

1. **资产清查确权**：组建住建、城管、财政、国企联合专班，对全域排水设施进行全覆盖盘点，建立电子化资产台账[^1]。
2. **按效付费试点**：选择1-2个污水处理厂或片区，试行按效付费考核机制，积累经验后逐步推广[^2]。
3. **智慧排水规划**：启动排水管网GIS系统建设，优先在重点区域布设液位、水质在线监测设备[^7]。
4. **雨污混接排查**：对建成区雨污水管网进行全面排查，建立混错接问题清单与整改计划[^11]。

### 5.2 中期（2-4年）需推进事项

1. **厂网一体化整合**：推动成立或委托专业化排水公司，逐步实现全域统一运营[^6]。
2. **绩效考核体系全面建立**：将进水浓度、收集率、管网完好率、溢流控制等纳入常态化考核，实现“按效付费”全覆盖[^4]。
3. **联排联调机制建设**：建立气象、水利、住建、生态环境等部门信息共享与会商机制，实现排水系统联合调度[^9]。
4. **非开挖修复与更新改造**：对存量破损管网进行系统性修复，消除管网空白区[^11]。

### 5.3 长期（4-6年）需实现目标

1. **全生命周期资产管理常态化**：建立从规划、建设到运维、更新的全生命周期管理体系[^10]。
2. **智慧排水系统全面运行**：实现数字孪生平台、智能调度、AI辅助决策的全面应用[^7][^8]。
3. **雨水—污水协同良性循环**：形成“源头减排—管网高效—处理优化—资源利用—应急联动”的全链条协同体系。
4. **资金保障长效机制**：污水处理费标准动态调整，财政补贴与绩效挂钩，社会资本参与渠道畅通[^3][^12]。

| **深圳市** | 强化管网建设与管理，推行GIS系统管理，管网运营费与考核挂钩 | 管网移交率、运营效率显著提升 | [^15] |
| **桃源县** | 建立绩效考核评价机制实行按效付费，将运营补贴纳入财政预算 | 进水COD浓度、运行负荷率均达标 | [^5] |
